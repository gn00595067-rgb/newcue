## 資料流（目標）

```
[業務] 選客戶（Ragic 客戶表）→ 做 CUE（任一模式）→ 存檔（暫存，版本 v1）
          ↑ 讀回／線上修改（存 v2、v3…，留異動紀錄）
[業務] 送訂檔：補發票日、現折、退佣、收款日、上傳客戶回簽檔 → 狀態「待審」
[主管] 審核頁：看最新版 CUE ＋訂檔資料 → 退回（附原因）／核准
          核准 → 申請 CUE號（forms13/4）→ 回寫 CUE號 → 每波建訂檔（forms12/17，含收入子表、附件）→ 狀態「已訂檔」
```

CUE 狀態：`草稿` →（送訂檔）`待審` →（核准）`已訂檔`／（退回）`草稿`。
「待審」「已訂檔」狀態下業務不能直接改；已訂檔要改 → 走需求三「檔次調整」產生新版本並重新送審（異動單）。

### 第 2 期：CUE 存檔／讀回／線上維護（需求二、四）— 約 3 天

2. 同一份 CUE 再存 = **更新同一筆、版本 +1**（不是新增一筆），異動內容記到「異動紀錄」子表（時間、人、改了什麼）。
3. 「我的 CUE」列表：依業務／客戶／狀態查詢，點開即還原到對應模式繼續編輯。

### 第 3 期：既有 CUE 檔次調整（需求三）— 約 3 天
1. 選一份已存檔 CUE → 指定日期區間＋平台 → 調整／增加每日檔次（表格直接改）→ 自動重算金額 → 存新版本。
2. 異動紀錄寫明：哪個平台、哪段日期、檔次由 X 改 Y、實收變化。
3. 已訂檔的 CUE 調整後狀態回到「待審」，核准後更新訂檔（或另開異動訂檔，待確認營運流程）。

### 第 4 期：送訂檔、主管審核、自動 CUE號、自動訂檔（需求五、六）— 約 4 天
1. 業務「送訂檔」：補發票開立日、現折、退佣（預設帶客戶主檔）、收款日期、個案狀況、上傳客戶回簽檔（訂檔表必附）→ 必填檢查（沿用 `missing_required_order`）→ 狀態「待審」。
2. 營運主管「審核」頁：列出待審件，看 CUE 預覽＋訂檔資料＋異動紀錄 → 核准／退回（必填原因）。
3. 核准時自動：申請 CUE號（forms13/4，填申請人、客戶編號、起走日、總波段）→ 讀回 CUE號 → 每波建一張訂檔（forms12/17）：收入子表依平台細項彙總檔數、秒數、實收未稅；附件＝CUE Excel＋客戶回簽檔 → CUE號、訂檔流水號回寫到 CUE 存檔。
4. 先做「乾跑預覽」模式（顯示將寫入的內容不送出），確認幾筆無誤再開正式寫入（cueupload 已有此設計）。
