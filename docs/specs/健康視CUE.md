## 3. 計算
- 每一個「專案價未稅」的預算 ＝ 384,000 次曝光，各秒數都一樣。
- 曝光次數 ＝ round(384,000 × 預算未稅 ÷ 專案價未稅(秒數))
  - 例：10秒、預算 50,000 → 384,000 × 50,000 ÷ 166,666.67 ＝ **115,200**
  - 例（參考檔）：15秒、預算 300,000 → **460,800**
- 定價欄 ＝ round(定價未稅(秒數) × 預算 ÷ 專案價未稅(秒數))
  - 例（參考檔）：15秒、300,000 → 375,000 × 300,000 ÷ 250,000 ＝ **450,000**
- 專案價欄 ＝ 預算（未稅）；5% VAT ＝ round(預算 × 0.05)；專案含稅價 ＝ 預算＋VAT。
- 預算下限：大於 0 即可（宜歆例子有 5 萬）；之後若有最低承購額再加。

## 5. CUE 版面（照參考檔）
- 抬頭：依格式換公司名稱和標誌
  - 鉑霖：「鉑霖行動行銷-媒體計劃排程表 Mobi Media Schedule」＋Mobi 標誌
  - 東吳、聲活：用各自現有的抬頭和標誌
  - 第二行固定「全民健康視專案」
- 表頭：TO（客戶）、FROM（公司 - 業務）、客戶名稱、廣告名稱。
- 表格只有一列，欄位：

| 欄位 | 內容 |
|---|---|
| 頻道 | 全民健康視（換行）全科別診所 |
| 播出地區 | 全台 |
| 播出店數 | 300+面 |
| 播出時間 | 07:00-22:00 |
| 規格 | {秒}秒（換行）影片/影像 1920x1080 (MP4) |
| 執行期間 | MM/DD-MM/DD（換行）執行週一至週五（或「執行每日」）；**沒有每日落點** |
| 曝光次數 | 自動算 |
| 定價 | 自動算 |
| 專案價 | 預算 |

- 表格下面依序：
  - Total 列
  - 廣告主、統一編號、客戶簽章
  - 右下角三列：製作＝「客戶提供」、5% VAT、專案含稅價（藍字）
- 備註（健康視專用，不用 `utils.get_remarks_text`）：
  - 開頭：Remarks：本排程表經雙方確認後視同合約之延伸，具同等法律約束力與效力
  1. 請於 {回簽日 YYYY/MM/DD (週)} 下午1500前回簽。（紅）
  2. 因應場域屬性，診所開診與休診時段不一，故不保證每家診所每日與各時段曝光次數維持一致，曝光記錄以後台系統數據為最終依據。
  3. 託播方需於上檔前 5 個工作天，提供影片/影像 1920x1080 (MP4)。（紅）
  4. 雙方同意費用請款月份 : {請款月份} ，如有修正必要，將另行告知，並視為正式合約之一部分。
  5. 付款兌現日期：{付款兌現日}前兌現。
  6. 若實際曝光次數未達購買總量，將延長執行期至達成保證曝光數為止。（藍）
- 輸出 Excel（值版）＋PDF。
- 檔名：`MMDD 客戶 全民健康視({秒}秒) {預算萬}萬-業務`。
