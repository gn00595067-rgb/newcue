## 需求 1：一鍵CUE 可選東吳／聲活／鉑霖抬頭

### 審視
- BA：業務用一鍵CUE 出的單要以哪家公司名義簽，現在只能手填乙方、大標永遠是 Media Schedule，出給客戶不像該公司的單。
- PM：回饋字面是「抬頭」→ MVP 只換抬頭＋乙方，**不**把整張版面換成一般CUE 的聲活／鉑霖版型。
- SA：公司資訊（名稱、統編、標題、Logo）目前寫死在 `excel_renderer.py` 各 sub-engine 內 → 抽成一份 `COMPANY_PROFILES` 共用，一般CUE 與一鍵CUE 讀同一份。
- UX：格式選擇放在平台組合上方（與一般CUE 位置一致）；乙方欄位自動帶入，業務仍可改。

### 方案比較

| | A 只換抬頭（建議） | B 整張改用一般CUE 版型 |
|---|---|---|
| 做法 | 子公司版面不動，依格式換：大標、第3列公司行、Logo（鉑霖）、乙方名稱／統編預設值 | 把簡易模式 model 轉成一般CUE rows，交給 `generate_excel_from_scratch(format_type)` |
| 好處 | 版面維持宜歆 0902 範本、fidelity 測試照舊；工作量小（約半天） | 三家版面與一般CUE 100% 一致 |
| 代價 | 聲活／鉑霖版的「表格本體」仍是子公司樣式（欄位、顏色不同於一般CUE 聲活／鉑霖） | 一鍵CUE 的多秒數分頁、回饋列、預估曝光都要重接；一般CUE 聲活／鉑霖分頁是「依月」不是「依秒數」，要改 renderer；風險高 |

### MVP 規格（方案 A）
1. 一鍵CUE（`family="subsidiary"`）頂部加 radio「選擇格式：東吳／聲活／鉑霖」，預設東吳（＝現況輸出，不變）。
2. 依格式變動（Excel＋HTML 預覽同步）：
   - 東吳：維持現況（大標 Media Schedule）。
   - 聲活：大標「聲活數位-媒體計劃排程表」。
   - 鉑霖：大標「鉑霖行動行銷-媒體計劃排程表 Mobi Media Schedule」＋左上 Logo。
3. 乙方名稱／統編：切換格式時自動帶入該公司預設值（東吳 20935458、聲活 28710100、鉑霖 待確認），欄位仍可手改。
4. 檔名加格式前綴？→ 待確認（建議不加，與現況一致）。
5. 代理商分頁內的一鍵CUE（2008／凱絡模板）**不加**此選項（代理商版有自己的抬頭）。

## 需求 2：年約季約細CUE 套 2008／凱絡格式

### 審視
- BA：代理商（2008／凱絡）的年約，目前業務要每波手動到「代理商CUE」重打一次，或拿年約總表自己改。希望在年約季約畫面填完每波就直接出代理商格式。
- PM：MVP = 「每波一份 2008／凱絡 CUE」；**不**做「整年度總表」產出（2027 年約總表是同事手上既有的 Excel，當作填寫來源）。
- SA：代理商 CUE 已有 `build_agency_model(..., spots_override)`，每波 = 呼叫一次（全家 cfg＋萬家福 cfg，各給該波實收當 budget、檔次當 spots_override），再交 `generate_agency_excel`。不新寫 renderer。
- UX：格式選項擴成「東吳／聲活／鉑霖／2008／凱絡」；選代理商格式時：組合清單只能選全家廣播、萬家福．樂家康（新鮮視反灰並提示），區域固定全省，需代理商密碼。

### 主要卡點（需確認）
1. **新鮮視**：2008／凱絡格式不含新鮮視。年約若有新鮮視怎麼辦？→ 建議：代理商格式下不可加新鮮視組合。
2. **價格邏輯不同**：年約季約是「業務直接填檔次＋實收」；代理商CUE 是「依牌價／折讓由預算算檔次」，另有專案回饋列（全家凌晨時數轉換、萬家福回饋％）、代理商佣金（AC%）。
   - 建議：檔次、實收以業務填的為準（spots_override），回饋列沿用代理商預設規則，可關閉。需確認年約是否也要回饋列／AC%。
3. **區域**：代理商格式全家一律「全省」；年約若有分區組合（例如只買北區）無法表達 → 代理商格式下區域鎖全省。
4. **同一波多秒數**：代理商 model 每平台一個秒數一張分頁；年約同平台若有多個秒數組合 → 每秒數各一張分頁（需確認 `build_agency_model` 能否一平台多秒數，不能就每波拆多次呼叫後合併分頁）。

### MVP 規格（草案，待上面確認）
1. 年約季約「選擇格式」加入 2008、凱絡兩個選項（未解鎖代理商密碼時不顯示或點了要求密碼）。
2. 代理商格式下：組合只能選 全家廣播／萬家福．樂家康，區域固定全省。
3. 每波：每個組合填 檔次、實收（沿用現有輸入與「依波段天數均分」）。
4. 每波產出：HTML 預覽＋Excel＋PDF（沿用 `build_agency_html`／`generate_agency_excel`），檔名 `Cue_{代理商}_{客戶}_波段N_{起}_{迄}.xlsx`。
5. 不做：年度總表輸出、Ragic 上傳（同現行年約季約，MVP 不上傳）。

### 第二階段（視回饋）
- 「整年度總表」一張（12 個月或各波彙總）產出。
- 從同事的 2027 年約總表 Excel 直接匯入各波檔次／實收（省去手填）。→ 需先拿到該總表範本。
