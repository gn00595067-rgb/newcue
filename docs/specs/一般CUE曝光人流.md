# 一般 CUE 加入預估曝光／人流

## 需求（2026-09-30 Jonathan）
除代理商 CUE 外，所有 CUE 表都要呈現「總曝光次數」與「曝光期間店舖總人流量」。
簡易模式（七組合）已有；本次補到一般 CUE（東吳／聲活／鉑霖三格式，含年度季度 CUE，共用同一 renderer）。

## 呈現
- 文字格式與簡易模式相同（範本原文）：
  `【{平台}總曝光次數 : {曝光}     曝光期間店舖總人流量 : {人流} .】`
- 每個平台一行，依序：全家通路廣播 → TV（新鮮視）→ 萬家福．樂家康通路廣播；只列有投放的平台。
- Excel／PDF：寫在「製作／5% VAT／Grand Total」三列的 A 欄（左對齊、向右溢出），同簡易模式位置。
- HTML 預覽：費用區上方左側列出同樣文字。
- 分月多工作表時：每張表依「該月實際檔次」各自計算。

## 計算（共用 simple_reach 公式，不另寫一套）
- 全家／新鮮視：Σ 列(店數 × 該表內檔次)；人流 = 曝光 × TRAFFIC_FACTOR。
  店數取該列 program_num；加贈列（program_num 非數字）改用同平台同區域的店數。
- 家樂福（萬家福．樂家康）：曝光固定 860,000；人流依量販／超市檔次（region 含「超市」者算超市）。
- 回饋／加贈列都算入（同 REACH_INCLUDE_BONUS）。
- 檔次以該表 schedule 加總，不用 row["spots"]（分月切表時 spots 仍是全期）。

## 不做（MVP）
- 一般模式畫面上的曝光明細面板（簡易模式有）；需要再加。
- 代理商 CUE。
